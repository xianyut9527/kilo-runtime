基于 KiloCode 全局配置仓库的性能与质量专项收口版本。
Performance and quality consolidation release for the KiloCode global config repo.

### 性能 / Performance
- **网关快速换路**：404 与下线渠道纳入快速切换、全链冷却去重；修复熔断报文未进签名集导致每步白付 2s+6s 退避
  Fast switchover: 404 and retired channels handled, cooldown dedup, circuit-breaker signature fix (previously 2s+6s backoff paid per step)
- **流式首反馈**：reasoning delta 即达即转，工具回合不再首反馈死寂
  Reasoning delta streams through immediately, no silent first tool turn
- **「越用越卡」根治**：上下文负载 / 压缩位空响应真因收口，无效改动回滚
  Root-caused the progressive slowdown (context load / empty compaction), ineffective tweaks reverted
- **磁盘维护链修复**：三处静默不执行修复、`$HOME/.cache/kilo` 按目录 mtime 回收（实测 136MB 从未回收）、日志封顶、VACUUM 阈值自动化与同连接 auto_vacuum 转换
  Fixed three silent no-op maintenance paths, cache reclaim by dir mtime (136MB never reclaimed), log capping, automated VACUUM threshold with same-connection auto_vacuum
- **构建冒烟**：dist 新鲜度改内容指纹，src 改了而 dist 未重建不再假过
  Dist freshness by content fingerprint: stale dist no longer passes silently

### 质量 / Quality
- **quality-gate 三层门禁硬化**：新增层 0 需求覆盖门禁；修复层 2 验证门禁两条绕过路径、收紧高风险匹配；修补遥测盲区、假绿洞与 LRU 丢状态
  Hardened three-layer gate: new layer 0 requirement coverage, two layer 2 bypass paths fixed, high-risk matching tightened, telemetry blind spots and false-green holes patched
- **permission-guard**：破坏性命令按命令位锚定，消除只读检索误伤
  Destructive commands anchored to command position, read-only search false positives removed
- **provider 可靠性**：AbortError 全链贯通（退避与门控重试不再吞取消）、断路器预检死锁修复、diff→test 关联断言
  Provider reliability: cancellation fully propagated, preflight deadlock fixed, diff→test assertions
- **全局记忆 v3**：锁原语 / 写管线 / 观测 / 部署冒烟隔离；封顶机制根治两处无限增长源
  Global memory v3: locking, write pipeline, observability; cap mechanism fixed two unbounded growth sources
- **测试网**：db-maintain 离线回归 39 项锁死行为契约，全套 11 套件全绿
  Test net: 39 db-maintain regression cases, 11 suites all green
