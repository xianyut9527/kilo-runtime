# 项目级智能包模板

这些模板用于真实项目，而不是全局仓库本身。

## 使用方式

1. 选择最接近的模板目录。
2. 复制其中的 `AGENTS.md`、`.kilo/skills/`、`.kilo/commands/` 到目标项目根目录。
3. 用项目真实信息替换占位符，例如技术栈、验证命令、边界约定、关键模块。
4. 删除不适用的 skill 或 command，避免把无关说明带入项目上下文。

## 模板说明

- `backend-service/`: 适合后端服务、API、任务处理、数据同步等项目。
- `frontend-web/`: 适合 Web 前端、管理台、组件库、单页应用等项目。
- `fullstack-system/`: 适合多服务协作、前后端一体、事件流和跨模块链路较多的系统。

## 维护原则

- 模板只提供结构和高价值占位符，不硬编码真实项目命令、目录或领域名词。
- 项目级知识优先进入 skills 和项目 AGENTS，而不是继续扩大全局规则。
- 每次新增模板能力时，优先保证精简和可替换性。
