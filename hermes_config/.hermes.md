# 项目上下文规则

本文件由 Hermes Agent 自动加载，定义当前项目内的强制编排规则与交付标准。

---

## 强制编排锚点

1. **意图判定优先**：任何任务先判定「咨询类 / 执行类」。咨询类只分析不改文件；执行类才进入后续流程。
2. **执行类三段开场白**：意图判定 → 任务定级（T0-T3）→ 强制流程日志（≥7 节点），然后才可调用修改性工具。
3. **定级前置**：命中安全敏感关键词（user/auth/payment/wallet）→ 最低 T2。
4. **单元闭环**：T1+ 任务拆为可验证小单元，每单元独立 delegate_task（engineer 子代理）→ checker 子代理 → fixer 子代理 闭环。
5. **验收必附映射表 + 已读取文件清单**：每条验收标准 → 实现位置 → 验证方式 → 边界覆盖 → 状态。缺则 FAIL。
6. **SCOPE_CREEP**：checker 子代理 L2 反向核对 diff，扫描验收标准未声明的改动，命中即 FAIL。
7. **自验无效**：engineer 子代理不得自验，必须过 checker 子代理客观验证。
8. **memory / skills / 自进化合规**：任务启动加载 `MEMORY.md` + `USER.md`；方法层/需求层失败触发跨会话根因回溯（`session_search` + `gitnexus` MCP）；经验回写必须经闭环验证。
9. **流程违规即停**：发现跳步立即标 `[PROCESS_VIOLATION]` 并暂停。
10. **临时文件**：写入系统临时目录，禁止污染项目目录。

---

## 核心工具

- `delegate_task`：创建独立上下文子代理
- `session_search`：跨所有历史会话全文检索
- `gitnexus` MCP：代码图谱、影响面分析
- `execute_code`：Python 脚本批量调用工具
- `memory` / `fact_store` / `fact_feedback`：持久记忆与信任评分
- `skill_manage`：运行时维护 skills

---

## 一次性完成判定

本配置追求 SOTA 级编码输出质量。一次任务只有满足以下全部条件，才视为"一次性完成"：

1. **正向验证通过**：实现满足所有验收标准，验收映射表完整，边界覆盖（正常/空值/异常）到位。
2. **反向验证通过**：diff 中无验收标准未声明的改动（SCOPE_CREEP），无调试代码、临时文件、重复实现残留。
3. **双重检查通过**：正向 checker 与反向 checker 均独立 PASS。
4. **三视角审查通过**：reviewer 从安全、架构、简化三视角审查无 blocker。
5. **无 fixer 修复轮次**：从 engineer 输出到最终交付，未触发 fixer 子代理。

任一条件不满足，任务仍可交付，但不标记为"一次性完成"，并应在交付回顾中记录根因，触发经验回写评估。

## 本地记忆说明

Hermes 内置记忆（`~/.hermes/memories/MEMORY.md`、`USER.md`）属于**个人/设备本地资产**，不纳入本仓库版本控制。团队共享的项目规则应写入 `SOUL.md`、`.hermes.md` 或 `skills/`。

---

## 安全约束

⚠️ **禁止写入以下内容到任何版本控制文件**：
- API Key / Token / 密码 / 凭证
- 内部域名 / IP 地址 / 内部 URL
- 个人身份信息（PII）
- 任何受 NDA / 保密协议保护的内容

## 子代理委派策略

| 角色 | 时机 | toolsets |
|------|------|----------|
| engineer | 局部清晰实现 | `["terminal", "file"]` |
| checker | 验证（不修复） | `["terminal", "file"]` |
| fixer | 定向修复 checker 问题 | `["terminal", "file"]` |
| reviewer | T1+ 总体验收 | `["terminal", "file"]` |
| architect | T2 跨模块规划 | `["file"]` |
| pre-checker | T1+ 方向预审 | `["file"]` |

---

## 交付格式

交付输出开头必须标记 ✅/⚠️/❌，包含：
1. 闭环确认（验收 → 实现位置 → 验证证据 → 状态）
2. 变更回顾（改了什么 / 为什么改 / 影响范围 / 清理调试代码）
3. 经验沉淀（踩坑记录 / 可复用发现 → 回写 MEMORY.md/SKILL.md）
