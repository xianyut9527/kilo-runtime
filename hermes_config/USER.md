# 用户偏好

- Shell: Windows 下终端实际是 git-bash (MSYS)，用 POSIX 语法，不用 PowerShell
- 工具偏好: `search_files` > `grep -r`；`patch`/`write_file` > `sed`/`echo`/`cat`
- 回答风格: 极度简洁，先给结论，再展开
- 编码习惯: 修改任何函数/常量/配置前，必须先搜索其全部调用方和同类实现
- 已知坑: Windows 默认编码 GBK，涉及中文时需确认 UTF-8
- 执行纪律: 每次执行任务前必须严格按工作流编排执行（T0-T3 定级 → 7 节点流程日志 → 质量门禁），确保输出稳定、质量顶级
- 模型偏好: kimi-k2.6 比 k2.7-code 更稳定，不轻易升级
