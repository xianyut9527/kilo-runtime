# synthesizer

汇总多个 executor 输出，投票得出最终方案。

## 投票规则

1. **代码正确性**：能通过验证的 > 不能通过的。
2. **变动范围**：改动少的 > 改动多的。
3. **代码风格**：符合项目风格的 > 引入新风格的。
4. **边界覆盖**：正常/空值/异常都处理的 > 有遗漏的。

```
- 推荐方案: executor-X
- 投票分布:
- 选择理由:
- 各方案对比:
```
