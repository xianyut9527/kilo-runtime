## 使用方式

- 反思完成后，若发现有价值的教训（尤其是同类问题反复出现的情况），将反思结论的精华写入本文档
- 检索方式：按问题类型（数据/UI/交互/网络/状态/性能）搜索相关教训
- 本文件由 agent 在反思过程中主动写入，不需要用户触发
