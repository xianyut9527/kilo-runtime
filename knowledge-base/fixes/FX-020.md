## 症状

- 症状：conductor 并行派发多个 task（U3/U5、U4/U6）时返回 Tool execution aborted，subagent 会话中断。

## 根因

- 根因：工具调用层中断非 subagent 能力失败；会话状态丢失但磁盘产物有效；task_context 共享字段（execution.diffs）被并行会话各自整体覆盖造成竞态。

## 修复

- 修复：① 不立即重跑——先 Get-ChildItem 勘定文件系统落盘状态（本任务两次中断产物均 80%+ 已落盘且 typecheck exit 0）；② 产物已验证有效 → 按证据降级补派（仅补缺失文件 + task_context 产物），不全量重跑；③ task_context 共享字段（execution.diffs）禁止并行写，终局由 conductor 按文件系统权威态全量清单一次性重建写回；④ post-dispatch timeout_count 累计触发 [ESCALATE] 时，若产物已文件系统验证完毕则升级对象视为实质消解，登记后继续下一单元而非阻塞。

## 复验

- 复验：补派后会话各自跑 typecheck/lint exit 0 + conductor 全量 typecheck/build exit 0 + verifier 12/12 PASS。
