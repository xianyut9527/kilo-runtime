## 症状

- 修改 agent/*.md frontmatter description（如 verifier 5元组→8元组）后，lifecycle-doctor 报 prompt-sync FAIL：desc(N)!=prompt(M)，SUMMARY 1 FAIL，[ASSEMBLY_FAIL] 阻断运行

## 根因

- kilo.json agent.<name>.prompt 由 agent/*.md frontmatter description 派生，但派生非自动——需显式跑 sync-agent-prompt.mjs 同步。改 description 不同步 prompt 即双源漂移

## 修复

- 改 agent/*.md description 后，跑 node scripts/sync-agent-prompt.mjs（或 build-derivations.mjs）同步 kilo.json agent.prompt，再跑 lifecycle-doctor 确认 prompt-sync PASS

## 复验

- node scripts/lifecycle-doctor/index.mjs → SUMMARY 0 FAIL，无 ASSEMBLY_FAIL
