## 症状

- 终检 grep 禁词命中数=1 但 coder 仍报 PASS
- 新增文案自身含禁词：描述禁止项时直接把禁词原词写进文案（如「无 X 无渐变」而 X 正是禁词）
- 全文终检被这一行卡死，反复 FAIL 无法收敛
- 注：本条正文故意不复现具体禁词，以免自身触发同类自嵌套

## 根因

- 描述禁止项时直接引用禁词本身（自嵌套），验证正则无法区分「描述禁用」与「实际使用」

## 修复

- 描述禁止项改用同义替代词：把「无 X」改写成对该效果的中文描述（如发光效果 / 渐变 / 阴影）
- 写完 AC 禁词清单后，新增文案先对照清单自查一遍再落盘

## 复验

- 目标范围 grep 禁词与其中文同义词均为 0 命中
- 全文终检禁词组 0 命中
