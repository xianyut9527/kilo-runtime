## 症状

- verifier round2 FAIL：context_anchor 描述的行号代码（htmlClass/markPath/MutationObserver）在工作区 grep 0 命中
- fixer 声明 PASS 但磁盘状态与声明不符，疑似 subagent 虚报

## 根因

- 用户在会话外并行改写工作区（v2 SVG 方案改为 v3 纯字体重写版，含 3 个 SVG 资源更新），staged 与 worktree 双版本并存
- round2 verifier 读到工作区 v3 版，误将外部改写定性为 fixer 未落盘

## 修复

- git diff --cached 与 git diff HEAD 双查，区分 staged/worktree 双版本
- 确认外部改写后不回滚不覆盖用户改动，以工作区现状为新基准重派 verifier 终验
- 禁止 git checkout -- 覆盖用户工作区改动

## 复验

- git diff --cached --stat 与 git diff HEAD --stat 对比：双版本并存即命中本条
- 重验 verdict 以工作区基准 round3 输出为准
