# FX-0003：`permission.ask` 不是 plugin hook

- **标签**：plugin, permission
- **症状**：插件里实现 `permission.ask` 后从不被调用；想拦截危险 bash 命令却拦不住（无报错也无效果）。
- **根因**：`permission.ask` 与 `permission.edit` 属于 **config 静态权限**（`kilo.json` 的 `permission` 段），**不是** plugin hook。Plugin 可用的 hook 是 `tool.execute.before` / `tool.execute.after` / `chat.params` / `event` / `experimental.session.compacting` 等。
- **修复**：动态守护（按参数内容判断是否危险）必须用 `tool.execute.before`：签名 `(input={tool,sessionID,callID}, output={args})`，**在 hook 内 `throw` 即可 veto 工具执行**（实测可行）。
- **示例**：见 `plugin/permission-guard.ts`（拦截 `git push --force`、`rm -rf`、`git clean -fd`、`reset --hard`、`npm publish`、fork bomb，及 `.ssh`/`.aws`/`.kube`/`auth.json`/`id_rsa` 敏感路径）。
