# FX-0002：`.md` agent 摧毁内置提示词

- **标签**：agent, plugin
- **症状**：在 `.kilo/agent/` 或 `~/.config/kilo/agent/` 放置 `<内置名>.md` 后，该内置 agent 的原有系统提示词消失（只剩 `.md` 内容）。
- **根因**：实测 7.6.2：内置 agent 实为 10 个 —— `ask` `code` `compaction` `debug` `explore` `general` `orchestrator` `plan` `summary` `title`（清空 config `agent` 段可复现）。同名 `.md`/config 定义会**整体覆盖**内置提示词，而非追加。
- **修复**：
  - 内置 agent（上述 10 个）**一律不要**写同名 `.md`，改提示词请用 `kilo.json` 的 `agent.<name>.prompt` 增量补充（仍会覆盖，需完整意图）。
  - **非内置** agent 用 `.md` 合法且必要 —— 本项目 `verify` 即 config `agent.verify` 创建（`native=false`），`agent/verify.md` 是它的提示词载体。
- **验证**：`kilo debug agent` 可列出全部 agent 及来源。
