基于 KiloCode 全局配置仓库的单模型测试模式与可靠性收口版本。
Single-model testing mode and reliability consolidation release for the KiloCode global config repo.

### 新增 / New
- **严格单模型测试模式**：新增 `single` agent 与 `scripts/single-model.mjs`，模型硬锁、禁用委派/多模型审查/规划/技能/记忆工具，quality-gate 出口豁免；enter/restore 原子状态与审计日志，锁定期间安装脚本拒绝覆盖配置
  Strict single-model testing mode: new `single` agent and `scripts/single-model.mjs` with hard model lock, delegation/review/planning/skill/memory tools disabled, quality-gate exit exemption; atomic enter/restore state with audit log, installer refuses config overwrite while locked
- **供应商可替换说明**：README 说明默认使用 OpenLlamas，也可替换为自己的模型供应商与 API Key
  Custom provider guidance: README documents OpenLlamas as the default and how to use your own provider and API key

### 可靠性 / Reliability
- **故障转移**：400 区域策略、402 余额不足纳入换路；413 请求体过大逐级裁剪工具输出、调用参数与历史后原地重试；修复断路器半开探针误开与并发迟到响应污染；错误正文统一上游原文直传
  Failover: 400 region policy and 402 quota now switch channels; 413 payloads are trimmed (tool output, arguments, history) and retried in place; circuit-breaker half-open and late-response fixes; upstream error text passed through verbatim
- **审查链路**：正/反/裁决三席支持配置化 fallback 与共享墙钟预算；聚合保底窗口避免 fallback 饿死；超时与取消贯通底层请求；降级复核显式标注；连续审查失败阻断交付
  Review pipeline: configured fallbacks with shared wall-clock budget; aggregation floor window prevents fallback starvation; cancellation propagates to underlying requests; degraded reviews are labeled; delivery is blocked after repeated review failures
- **数据库维护**：event 批次降至 20000 降低写锁冲突；孤儿数据按 rowid 分批回收；清理后按空闲页比例决定 VACUUM，压缩前二次检查写者；每日双触发调度与 `-VacuumNow` 离线压缩入口
  DB maintenance: smaller event batches reduce write-lock contention; orphan rows reclaimed by rowid; VACUUM decided by free-page ratio with writer re-check; daily dual-trigger schedule and `-VacuumNow` offline entry point
- **全局记忆**：同 id 合并（flags/hits/pinned 语义），锁内重读避免并发写覆盖
  Global memory: same-id merge semantics (flags/hits/pinned), locked read-modify-write avoids lost updates

### 配置 / Config
- **模型路由**：主力、轻量、探索、压缩、编排与规划角色重新绑定，新增豆包 Seed 2.1 Pro；模型名以 `kilo.json.tmpl` 为唯一真源
  Model routing: rebound main/light/explore/compaction/orchestrator/plan roles and added Doubao Seed 2.1 Pro; `kilo.json.tmpl` remains the single source of truth
- **verify 静态权限**：补齐计划任务、Shell 与 PowerShell 包装器封禁，堵住只读约束逃逸
  verify static permissions: scheduled-task and shell-wrapper escapes now blocked

  Windows: `.\install.ps1` (`-DryRun` to preview); macOS / Linux: `./install.sh`
