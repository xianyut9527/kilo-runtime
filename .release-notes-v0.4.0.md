跨平台安装一致性与单模型并发安全收口版本。
Cross-platform installation consistency and single-model concurrency safety release.

### 安装 / Install
- **跨平台路径与 URL**：`file://` 路径按 RFC 3986 百分号编码，统一 Windows/POSIX 与 `--target` 归一化，修复空格、特殊字符、相对路径、8.3 短名与尾随分隔符导致的非法配置 URL 与路径误判
  Cross-platform paths and URLs: `file://` path segments are RFC 3986 percent-encoded; Windows/POSIX and `--target` normalization are unified, fixing invalid config URLs and path misjudgment caused by spaces, special characters, relative paths, 8.3 short names and trailing separators
- **完整性闸门**：provider dist 指纹缺失或过期时默认阻断安装，`-Force` / `--force` 可人工豁免；新增 Node 版本窗口检查，避免类型剥离不受支持时的冒烟假失败
  Integrity gate: install is blocked by default when the provider dist fingerprint is missing or stale, with `-Force` / `--force` for manual override; a Node version window check avoids false smoke failures when type stripping is unsupported
- **行尾与指纹**：源码指纹统一按 LF 归一化，`.gitattributes` 固定行尾，修复 Windows CRLF 工作区误判 dist 过期
  Line endings and fingerprints: source fingerprints are normalized to LF and `.gitattributes` pins line endings, fixing false stale-dist detection on Windows CRLF worktrees
- **脚本兼容性**：安装脚本改用 BSD/GNU 通用命令并转义模板替换值；`cleanup.sh`、`db-maintain.sh` 恢复可执行权限
  Script compatibility: installers use BSD/GNU-portable commands and escape template substitutions; `cleanup.sh` and `db-maintain.sh` regain executable bits

### 并发与可靠性 / Concurrency & Reliability
- **单模型锁**：锁文件原子写入并校验属主，残留或损坏锁需 `--force` 接管；收紧备份权限并支持备份丢失恢复，避免配置损坏与状态死锁
  Single-model lock: lock files are written atomically with owner validation; residual or corrupt locks require `--force`; tighter backup permissions and recovery from missing backups prevent config corruption and state deadlock
- **请求取消**：`hx-client` 提前拦截已耗尽的墙钟预算并组合外部取消信号，确保用户中止与会话结束能及时终止请求
  Request cancellation: `hx-client` rejects exhausted wall-clock budgets early and composes external cancel signals, so user aborts and session shutdown terminate requests promptly
- **审查标注**：正/反/裁决同源时显式标注，避免把单模型复核计为三族独立交叉验证
  Review labeling: same-family positive/negative/aggregator seats are labeled explicitly, so single-model review is not counted as three-family independent verification
